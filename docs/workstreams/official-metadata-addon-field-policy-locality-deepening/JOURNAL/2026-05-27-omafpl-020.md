# OMAFPL-020 Provider-Owned Default Field Preferences

Date: 2026-05-27
Status: DONE

## Summary

Moved default AV field provider order facts out of central registry arrays and into provider-owned
catalog descriptors.

Implemented:

- Added `ProviderDefaultFieldPreference` to describe provider-owned order for canonical field
  groups.
- Added `default_field_preferences` to `ProviderCatalogEntry`.
- Changed `ProviderRegistry::default_av_provider_field_policy` to fold catalog descriptors into a
  `ProviderFieldPolicy`.
- Generalized `ProviderFieldPolicy::from_field_provider_preferences` so the registry can pass
  composed vectors instead of static provider slices.
- Removed `DEFAULT_*_PROVIDER_ORDER` and `DEFAULT_FIELD_PROVIDER_PREFERENCES` from the registry.

## Verification

- `cargo nextest run -p nako-metadata-scraper provider_field_policy registry default_av_provider_field_policy --no-fail-fast` passed, 17 passed, 259 skipped.

## Notes

The quality-score preset remains descriptor-driven through `field_quality` and was intentionally not
changed.
