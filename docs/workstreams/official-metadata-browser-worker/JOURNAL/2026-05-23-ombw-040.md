# OMBW-040 Douban Browser-Backed Baseline

Date: 2026-05-23
Status: DONE_WITH_CONCERNS

## Summary

- Added a stable `POST /render` browser-worker contract that returns final URL, title, rendered HTML, normalized text, and excerpt.
- Kept site-specific metadata semantics in `nako-metadata-scraper` rather than moving Douban parsing into the worker.
- Added a Rust `douban` provider that renders Douban search/detail pages through the browser worker and parses provider facts from fixture-backed rendered HTML.
- Registered Douban in config, provider diagnostics, manifest configuration schema, README docs, and Compose defaults.

## Concerns

- Live Douban access was not proven. The accepted baseline is recorded fixture-backed because real access can depend on proxy, cookies, rate limits, or anti-bot state.
- The Douban parser is intentionally narrow: one search result and one movie detail shape. Broader selectors and live-smoke policy should be a follow-on before claiming production breadth.
