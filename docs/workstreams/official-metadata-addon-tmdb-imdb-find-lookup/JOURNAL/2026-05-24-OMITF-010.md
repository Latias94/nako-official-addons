# OMITF-010 — Scope And Lookup Policy

Opened the TMDB IMDb find lookup lane on 2026-05-24.

## Decisions

- Use TMDB's official `/find/{external_id}` API with `external_source=imdb_id`.
- Keep native query `tmdb` ID precedence.
- Treat failed, empty, or malformed find responses as title-search fallback.
- Do not copy reference repository code or fixtures.
