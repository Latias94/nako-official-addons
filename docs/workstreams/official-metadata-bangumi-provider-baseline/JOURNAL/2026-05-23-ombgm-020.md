# OMBGM-020 - Provider Surface

Status: DONE
Date: 2026-05-23

## Changes

- Added `ProviderId::Bangumi`.
- Added `BangumiProviderConfig` with optional access token, API base URL,
  configurable User-Agent, NSFW flag, and subject-type filter.
- Added Bangumi to manifest provider schema and optional secret-reference
  fields.
- Added Bangumi to provider registry diagnostics and catalog.
- Added a no-result `BangumiMetadataProvider` placeholder so registry
  construction is real before adapter implementation.
- Updated the checked-in example manifest for the new default provider schema.

## Validation

- `cargo nextest run -p nako-metadata-scraper config manifest registry --no-fail-fast`
  passed with 18 tests and 15 skipped.
- `cargo fmt --all -- --check` passed.
- `git diff --check` passed with only the Cargo.lock line-ending warning.

## Notes

- Bangumi is disabled by default.
- Bangumi public-read construction does not require a token.
- Optional token fields remain redaction-safe and are not printed in
  diagnostics.
