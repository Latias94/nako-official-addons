# OMBME-020/030 Subject Fact Enrichment And Docs

Implemented Bangumi subject fact enrichment in the provider parser/mapper.

Added optional parsing for official subject fields:

- `nsfw`
- `locked`
- `series`
- `volumes`
- `air_weekday`
- `collection`

Mapping behavior:

- Emits deterministic provider-prefixed tags for NSFW, locked, series,
  subject type, volume count, episode counts, valid air weekday, platform,
  rating facts, collection total, selected production values, and selected end
  date values.
- Detects official-site infobox presence but does not write concrete homepage
  URLs into `patch.tags`.
- Keeps protocol compatibility by avoiding new `AddonMetadataPatch` fields.
