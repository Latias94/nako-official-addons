# OAABH-010 Scope Freeze

Opened `official-addons-architecture-boundary-hardening` after local review of
`nako-official-addons` and `../nako`.

Key findings:

- official catalog/runtime manifest facts are still duplicated for
  resource-search, subtitle-provider, and DLNA;
- Nako server addon app-service parent module still owns too many user-facing
  addon workflows;
- metadata provider HTTP runtime needs explicit operation policy before live
  provider scale increases further;
- notification bridge route locality is a cleanup candidate;
- mature provider model research docs are stale after resolver/capability work
  landed.
