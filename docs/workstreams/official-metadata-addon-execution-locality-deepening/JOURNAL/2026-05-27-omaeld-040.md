# OMAELD-040 - Render Drift Case Locality

Date: 2026-05-27
Status: DONE

## Summary

Render drift case generation no longer hard-codes each provider branch in `render_drift.rs`.

Shipped shape:

- `ProviderCatalogEntry` now carries an optional `ProviderRenderDriftCaseDescriptor`.
- Provider entries own render drift sample env, fallback, output order, and case builder facts.
- `browser_worker_render_drift_cases_from_lookup` now filters enabled provider entries, resolves
  samples, builds cases through descriptors, sorts by descriptor order, and returns cases.
- The central runner no longer imports every rendered provider module just to build drift cases.
