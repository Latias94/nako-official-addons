# OMAELD-020 - Bulk Provider Execution Typed Facts

Date: 2026-05-27
Status: DONE

## Summary

Bulk Metadata Scrape no longer mutates item request JSON to inject `provider_execution_policy`.
The scrape path now uses typed ProviderRunPolicy facts:

- `ProviderRunPolicy` gained typed overlay helpers for disabled provider ids and per-item selected
  provider budget.
- `MetadataScrapeRuntime` gained a typed internal scrape path that accepts a ProviderRunPolicy.
- `bulk.rs` builds a typed policy from request-visible policy, cooldown-disabled providers, and bulk
  provider budget.
- The obsolete `payload_with_provider_execution_policy`, `existing_provider_ids`, and
  `value_at_path` helpers were deleted.

Public scrape request parsing still intentionally supports `provider_execution_policy`.
