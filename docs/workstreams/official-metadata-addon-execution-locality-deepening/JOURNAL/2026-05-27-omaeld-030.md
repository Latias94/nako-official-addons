# OMAELD-030 - Provider Catalog Residual Locality

Date: 2026-05-27
Status: DONE

## Summary

Rendered-page proxy/session configuration checks no longer live in a central `ProviderConfigKind`
match inside `config.rs`.

Shipped shape:

- `ProviderCatalogEntry` now carries optional `ProviderRenderedPageSupport` facts.
- Each rendered provider entry points to its own rendered-page config accessor.
- `Config::rendered_page_proxy_policy_configured` and
  `Config::rendered_page_session_key_configured` delegate to `ProviderRegistry`.
- The duplicated central match for every rendered provider kind was removed.

This does not finish all provider catalog locality work, but it removes a concrete residual central
knowledge leak with fresh tests.
