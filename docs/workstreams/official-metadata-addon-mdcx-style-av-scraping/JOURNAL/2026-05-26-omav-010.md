- clean file names and normalize AV numbers before site search;
- classify number families such as FC2, censored, uncensored, amateur, western/date-like, and domestic;
- route to different provider groups from the normalized facts;
- separate search and detail fetches;
- preserve per-field/source evidence;
- process batches with bounded concurrency, resume state, and failure accounting.

Local repo fit:

- Browser-worker rendered HTML support already exists through Douban and should be reused for JavDB.
- The first vertical slice should add shared AV query facts, one JavDB provider baseline, and bulk diagnostics.
