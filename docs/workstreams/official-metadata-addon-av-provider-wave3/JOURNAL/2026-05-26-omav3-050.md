## Work Completed

- Evaluated MDCx FC2 long-tail references as strategy only:
  - FC2PPVDB: deterministic `/articles/{id}` detail URL with title, cover,
    release, actors, tags, seller, mosaic, runtime, and trailer-shaped fields.
  - FC2Hub: useful fallback, but requires search-to-detail resolution and has
    less release/runtime coverage in the reference strategy.
  - FC2Club: useful fallback, but more coupled to Chinese page labels and less
    appropriate as the first long-tail provider in this Rust sidecar.
- Selected FC2PPVDB for this slice because it improves fallback coverage without
  replacing the existing official FC2 source.
- Added disabled-by-default `fc2ppvdb` provider with browser-worker rendered
  HTML, FC2 route gate, deterministic article lookup, `fc2ppvdb_id` and
  `fc2ppvdb_url` direct lookup, external ID emission, field-quality descriptor,
  manifest/config/schema support, and docs.
- Added independent synthetic fixture tests covering search, direct ID lookup,
  direct URL lookup, route skip, long-tail field mapping, artwork, and trailer
  separation.
