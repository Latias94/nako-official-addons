Date: 2026-05-26

## Scope

Added Caribbean, 1Pondo, and 10Musume as disabled-by-default official
uncensored AV providers behind the existing browser-worker rendered HTML
contract.

## Implementation Notes

- Introduced a shared `official_uncensored` deep module with per-site descriptors
  for provider IDs, URL external ID providers, default base URLs, env vars,
  detail URL shape, provider outcomes, capabilities, and field quality.
- Added route support for official uncensored date-style IDs such as
  `010116-001`, normalized to canonical `010116_001` while preserving compact
  search terms.
- Each provider supports direct ID and direct URL lookup, emits provider URL and
  `av_number` external IDs, and maps title, overview, release/runtime, actors,
  tags, maker, label, series, director, poster, backdrop, and trailer facts.
- The parser now prefers row-level structured label extraction before falling
  back to full text label scanning so adjacent fields do not bleed into one
  another.
- Registry, config defaults, manifest schema, route diagnostics, README docs,
  and field quality descriptors include the trio.
