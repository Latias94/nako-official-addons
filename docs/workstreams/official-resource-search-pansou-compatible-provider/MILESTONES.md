# Milestones

## M1 - Provider Toggle Is Safe

Exit criteria:

- PanSou-compatible provider is disabled by default.
- Base URL is required before the provider can be active.
- Token debug output is redaction-safe.

## M2 - Mapping Is Deterministic

Exit criteria:

- PanSou result payloads map into internal search results.
- Merged-only payloads map into synthetic grouped results.
- Requested link type filters map to PanSou cloud types where supported.

## M3 - Ready For Live Manual Testing

Exit criteria:

- Focused tests pass.
- README explains how to enable a local PanSou-compatible service.
- Live service smoke remains optional.
