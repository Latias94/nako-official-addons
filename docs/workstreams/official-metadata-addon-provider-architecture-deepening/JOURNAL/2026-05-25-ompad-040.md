## Summary

- Added `crates/nako-metadata-scraper/src/providers/search_policy.rs`.
- Moved shared orchestration for direct lookup, title-variant search, search
  result dedupe, ranking-budget selection, partial-search preservation, and
  degraded candidate fallback out of TMDB/Bangumi provider implementations.

  result ID extraction, enrichment, and mapper logic inside each provider.
- Chose closure-based policy callbacks instead of a shared trait with associated
  result types, because the trait approach leaked provider-private raw/search
  result types into a broader interface.
