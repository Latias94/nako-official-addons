# OMAPAD-030 Single Provider Assembly

Date: 2026-05-25
Status: DONE

## Changes

- Added `ProviderAssembly` as the single registry output for ready provider
  adapters and provider diagnostics.
- Made `ProviderRegistry::providers()` and `ProviderRegistry::diagnostics()`
  derive from the same assembly path.
- Updated route construction to call `registry.assemble()` once.
- Moved health `network_policy` facts into provider diagnostics, with keys
  supplied by provider catalog entries.
- Stopped routes from reading `Config::provider_proxy_configured` directly.
