# ORSAF-020 Through ORSAF-040 Journal

Implemented the first plugin-side resource search foundation.

Changes:

- Added `nako-resource-search` workspace crate.
- Added alpha manifest, health, resource search, and diagnostics routes.
- Added typed request/response DTOs under the sidecar crate.
- Added deterministic fixture provider.
- Added link classification for common cloud drive and peer-to-peer link types.
- Added result fusion with URL normalization, deduplication, and source
  provenance preservation.
- Added packaging files, checked-in example manifest, and local smoke script.
- Recorded the deferred Nako host protocol proposal in `PROTOCOL_PROPOSAL.md`.

Validation:

- `cargo nextest run -p nako-resource-search --no-fail-fast` passed.
- `cargo fmt -p nako-resource-search -- --check` passed.
- `git diff --check -- Cargo.toml Cargo.lock README.md crates/nako-resource-search addons/resource-search docs/workstreams/official-resource-search-addon-foundation` passed with the existing Windows line-ending warning for `Cargo.lock`.
- `cargo build -p nako-resource-search` passed.
- `pwsh -File addons/resource-search/smoke.local.ps1 -SidecarBaseUrl http://127.0.0.1:9130` passed against a temporary local sidecar process.

Decision:

- Keep the current manifest resource as `automation` only as an alpha bridge.
  The correct long-term host contract is `resource_search` plus
  `acquisition_search_read`.
