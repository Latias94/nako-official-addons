# ORSAF-010 Journal

Opened the official resource search addon foundation workstream.

Key findings:

- PanSou is most useful as a domain reference for source aggregation, link
  taxonomy, fast partial search, result fusion, and link checking.
- Resource search is not metadata scraping. It should not share the
  `MetadataProvider` trait or metadata writeback policy.
- Nako already has host-side acquisition intake, but the current addon protocol
  does not have a dedicated resource-search resource or scope.

Decision:

- Start with an official `nako-resource-search` sidecar in this repository.
- Keep `../nako` code changes deferred. Record the protocol proposal in this
  workstream before opening a host-side lane.
