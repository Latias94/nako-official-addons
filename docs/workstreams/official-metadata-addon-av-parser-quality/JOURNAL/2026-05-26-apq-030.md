# APQ-030 Journal

Date: 2026-05-26
Status: DONE

## Scope

Audited JavLibrary, JavDB, and FC2 for parser helper reuse and migrated label
fields to the shared structured label fallback where it improved consistency.

## Implementation Notes

- JavLibrary now uses provider-local row selectors with shared structured label
  fallback for number, release/runtime, studio, publisher, series, director,
  rating fallback, and wanted fallback.
- JavDB now uses the shared helper for release/runtime, studio, publisher,
  series, director, wanted fallback, and detail-number fallback.
- FC2 now uses the shared helper for release/runtime and seller.
- Text, link, image, and URL helpers remain local because those providers have
  different page models and media semantics.
- JavDB and FC2 fixtures now use row-like metadata blocks so the structured
  parser path is covered by tests.
