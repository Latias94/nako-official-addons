# APQ-020 Journal

Date: 2026-05-26
Status: DONE

## Scope

Migrated DMM, MGStage, and JavBus label extraction to the shared structured
label helper where their detail pages have row-like metadata blocks.

## Implementation Notes

- DMM parser now uses `rendered_av::structured_or_labeled_value` with a
  provider-local `.product-info`/table row selector.
- MGStage now uses a provider-local `.detail`/`.product_detail`/table row
  selector for product ID, release/runtime, maker, label, series, director, and
  rating fallback.
- JavBus now uses a provider-local `.movie`/`.info`/table row selector for
  number, release/runtime, studio, publisher, series, and director fallback.
- DMM fixture now uses explicit row-like product-info entries so the structured
  path is covered rather than only the full-text fallback.
- Tests assert richer AV facts for DMM, MGStage, and JavBus, including series
  and director/studio/publisher fields.
