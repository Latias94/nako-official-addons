# APQ-010 Journal

Date: 2026-05-26
Status: DONE

## Scope

Promoted the official uncensored provider's row-level label extraction behavior
into `rendered_av` and migrated official uncensored plus FC2PPVDB to use it.

## Implementation Notes

- Added `rendered_av::structured_labeled_value` and
  `rendered_av::structured_or_labeled_value`.
- The shared helper reads labels from provider-supplied row selectors before
  falling back to full-text label scanning.
- Official uncensored keeps its provider-specific row selector locally.
- FC2PPVDB now uses the shared helper for release date, runtime, seller, actors,
  tags, and mosaic fields.
- FC2PPVDB deliberately uses direct child `.details > div` rows so the parser
  does not select the outer details block and swallow adjacent labels.
