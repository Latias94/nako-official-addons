# 2026-05-27 OMJ321

Implemented Jav321 as a raw HTTP provider.

Key decisions:

- Added `ProviderHttpRuntime::get_text` and `post_form_text` so providers can use bounded non-JSON responses without bypassing retry, timeout, and size policy.
- Modeled Jav321 search as `POST /search` with `sn=<AV number>` because the search response is already the detail HTML.
- Kept browser-worker rendering out of this provider; Jav321 has its own Rust-side proxy knob.
- Used the reference crawler and config as field-contract guidance only.
