## Summary

Added Nako host-side guarding for the External Acquisition Runner action task in
`../nako`. The generic Addon Task Run path now recognizes the external
acquisition action schema and applies acquisition-specific policy before the
job input is stored or dispatched.

The host requires direct dispatch, validates the typed action payload, rejects
unknown raw URL/password-shaped JSON before persistence, aligns host and runner
idempotency keys, requires audit refs for mutating operations, validates target
kind by operation, records runner status/state in task progress metrics, and
maps runner `rejected`, `failed`, or `not_found` action responses to failed
host task records with safe error codes.
