## Summary

Added `nako-external-acquisition-runner`, an official fixture/no-op Addon Task
sidecar for the External Acquisition Runner contract. The sidecar exposes the
official manifest, health endpoint, action task endpoint, and diagnostics page.

The runner deliberately stores job state in memory and implements only contract
semantics: enqueue, idempotent replay, query status, cancel, pause, resume, safe
progress facts, and redaction-safe diagnostics. It does not call qBittorrent,
Transmission, aria2, HTTP downloaders, cloud-drive services, or other external
runner targets.
