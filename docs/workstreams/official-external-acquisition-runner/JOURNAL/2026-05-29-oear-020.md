# OEAR-020 Journal - Host And Protocol Action Contract

Date: 2026-05-29
Status: Done

## Summary

Defined the External Acquisition Runner as an Addon Task surface instead of an
Addon Resource. The contract uses host-owned opaque target references,
dedicated `acquisition_action_run` scope, stable request/response schema IDs,
idempotency key, runner profile ID, action status, runner state, progress
facts, retry facts, and redaction-safe messages/facts.

## Implementation Notes

- Added task input/output schema fields to `AddonTaskDeclaration` so action
  tasks can advertise their payload contracts through manifests and Admin
  surfaces.
- Added protocol request/response types for external acquisition actions.
- Updated manifest validation to allow task-only sidecars; resource-less
  action sidecars are valid when they declare tasks or other addon surfaces.
- Added `nako.official.external-acquisition-runner` to the official catalog and
  server built-in catalog resolution.
- Kept real downloader adapters out of scope.
