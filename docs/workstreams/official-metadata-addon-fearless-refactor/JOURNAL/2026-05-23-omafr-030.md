# OMAFR-030 Journal

Date: 2026-05-23
Status: DONE

## Summary

OMAFR-030 replaced the shallow `default_providers()` construction helper with a
dedicated provider registry.

Key changes:

- Added `providers::registry::ProviderRegistry`.
- Moved provider construction behind a catalog that records provider ID,
  availability, capabilities, and constructor.
- Added `ProviderDiagnostics` and `ProviderDescriptor` for redaction-safe
  health/diagnostic output.
- Changed `MetadataProvider::id()` to return typed `ProviderId`.
- Kept `fixture` as an adapter behind registry construction.
- Updated routes to consume registry-built providers and registry diagnostics.
- Deleted `default_providers()`.
