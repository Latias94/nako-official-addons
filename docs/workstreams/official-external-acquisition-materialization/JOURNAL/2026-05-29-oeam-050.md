# OEAM-050 - End-To-End Contract Proof

Date: 2026-05-29

## Summary

Added the full fake host/sidecar proof for external acquisition
materialization.

The new Nako server test starts a real HTTP wrapper around the test router,
direct-dispatches an external acquisition action to a fake sidecar, has the
fake sidecar call `POST /addon/v1/acquisition/materialize` through
`NakoRuntimeClient` while the task is running, and completes the host task with
only redaction-safe action output.

## Changes

- Added a test HTTP wrapper for the Nako router in `nako-server` addon tests.
- Added a fake materializing external acquisition sidecar.
- Captured both the sidecar task dispatch request and the materialization
  request/response.
- Asserted the materialization request binds job id, declaration id, target ref,
  runner profile, idempotency key, and audit ref.
- Asserted the materialized response contains the host-owned magnet material.
- Asserted the completed host task response does not contain the raw material
  URI, selected-link candidate ref, idempotency key, or materialization ref.
