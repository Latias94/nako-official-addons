# OEAM-020 - Materialization Contract And ADR

Date: 2026-05-29

## Summary

Defined the protocol-level host-to-runner materialization contract in `../nako`.
This task did not add `nako-api` DTOs because the surface is an addon runtime
contract, not a browser/admin API contract.

## Changes

- Added ADR 0054:
  `../nako/docs/adr/0054-external-acquisition-materialization-boundary.md`.
- Added runtime route constant:
  `/addon/v1/acquisition/materialize`.
- Added materialization request/response schema constants.
- Added `AddonExternalAcquisitionMaterializationRequest`,
  `AddonExternalAcquisitionMaterializationResponse`, and
  `AddonExternalAcquisitionMaterializedLink`.
- Added `AddonExternalAcquisitionMaterializationPurpose`.
- Added `AddonExternalAcquisitionOperation::can_materialize_target()`, true
  only for `enqueue`.
- Added protocol tests proving stable wire names, unknown-field rejection, and
  Debug redaction for target refs, idempotency, audit, materialization refs,
  URI, and password material.
