# ONBPE-040 Provider Extension Proof

Date: 2026-05-25
Status: DONE

## Summary

Added a default-disabled `telegram` provider proof for
`nako-notification-bridge`. Telegram uses the Bot API `sendMessage` contract,
is configured only through sidecar-owned environment variables, and is covered
by local fixture tests rather than live-network defaults.

The provider proof covers:

- Telegram config parsing and safe `Debug`;
- safe health and `/ui/diagnostics` diagnostics;
- `library.scanned` provider delivery;
- sidecar-local `POST /providers/test-send`;
- exactly-one provider send path enforcement through the existing registry;
- redaction of API base URLs, bot tokens, chat ids, fixture hosts, template
  text, and raw event payload values from responses and diagnostics.
