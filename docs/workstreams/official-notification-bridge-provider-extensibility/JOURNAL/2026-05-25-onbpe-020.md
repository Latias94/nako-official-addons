# ONBPE-020 Provider Registry Seam

Date: 2026-05-25
Status: DONE

## Summary

Added a notification-bridge-local `provider_registry` seam and moved provider
diagnostics, configuration status, send-path counting, multi-provider
fail-closed error construction, selected-provider output, and generic
attempt-history mapping out of `routes.rs`.

The route handlers still own HTTP request/response handling and provider client
calls, but now consume registry-derived facts instead of duplicating provider
branching.
