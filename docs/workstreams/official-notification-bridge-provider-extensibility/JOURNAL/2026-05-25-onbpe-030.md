# ONBPE-030 Safe Provider Test-Send

Date: 2026-05-25
Status: DONE

## Summary

Added sidecar-local `POST /providers/test-send`. The endpoint sends a synthetic
safe `library.scanned` notification through the single configured provider and
returns only redaction-safe status.

The endpoint fails closed for:

- no configured provider send path;
- multiple configured provider send paths;
- invalid provider configuration;
- invalid enabled-provider template.
