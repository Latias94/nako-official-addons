# OACSH-040 Provider Descriptor Boundary

Date: 2026-05-24

## Changes

- Added provider-owned `catalog_entry()` functions for fixture, TMDB, Bangumi,
  browser worker, and Douban.
- Made `providers/mod.rs` compose the provider catalog from provider-owned
  entries.
- Made `ProviderRegistry` own catalog entry shape, provider build status,
  diagnostics, provider schema properties, and secret reference derivation.
- Updated manifest generation to consume registry-derived provider schema and
  secret references instead of knowing TMDB/Bangumi secret details directly.

## Evidence

  90 passed, 50 skipped.
- `cargo nextest run -p nako-metadata-scraper --no-fail-fast`: 138 passed, 2
  skipped.
- `cargo fmt --all -- --check`: passed.
- Path-scoped `git diff --check`: passed.

## Notes

This did not add dynamic plugin loading, macros, or a new install unit. It only
moved provider facts closer to provider modules.
