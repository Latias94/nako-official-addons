# OACSH-010 Scope Freeze

Date: 2026-05-24

## Decision

Do not open a new protocol release/versioning decision. ADR 0033 in `../nako`
already separates:

- Addon Version;
- Addon Protocol Version;
- Rust crate package version.

## Selected Follow-On Work

- Unify metadata scraper task envelopes with public `nako-addon-protocol`
  types.
- Harden the official live smoke harness.
- Move provider registry/config/diagnostic/schema facts toward provider-owned
  descriptors.

## Deferred Discussion

Future official addon-family splitting needs product design. Because the
current install model is sidecar-based, splitting capabilities into too many
installable sidecars may hurt operator experience. Keep this lane focused on
internal boundaries and smoke reliability.
